A visual overhaul mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** that changes the skin appearance of the protagonist (Anon) throughout all scenes, including shower scenes.

---

## 🎮 Features

- Custom skin textures for Anon across multiple gameplay perspectives and interaction scenes.
- Full compatibility with shower cutscenes and animations.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.97.11`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/anon-skin/releases) page and download `AnonSkin.zip`.
2. Navigate to your MDRG installation folder:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `AnonSkin.zip` directly into the `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/AnonSkin/mod.json
   ```
4. Launch the game. The mod will load automatically.
