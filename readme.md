A visual overhaul mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** that changes the skin appearance of the protagonist (Anon) throughout all scenes, including shower scenes.

---

## 🎮 Features

- Custom skin textures for Anon across multiple gameplay perspectives and interaction scenes.
- Full compatibility with shower cutscenes and animations.
- Compatible with MDRG version **v0.97.12** (Target: `0.97.11`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/anon-skin/releases) tab.
